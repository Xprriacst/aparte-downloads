# Aparté by Clareo Officines

Page et fichiers de téléchargement du pilote Aparté.

**Télécharger : https://xprriacst.github.io/aparte-downloads/**

Les installateurs incluent les moteurs locaux. Au premier démarrage, cliquez sur « Préparer Aparté » : les modèles (environ 3 Go) sont téléchargés et vérifiés automatiquement. Les entretiens peuvent ensuite être traités hors connexion. Une interruption du téléchargement permet sa reprise.

Windows : Windows 11, Intel/AMD 64 bits. Mac : macOS 12 minimum, choisir Apple Silicon ou Intel. Prévoir 5 Go libres ; 16 Go de mémoire sont conseillés. Les performances doivent être évaluées sur le poste utilisé.

Les fichiers SHA-256 joints aux versions permettent de contrôler les installateurs. Ils ne remplacent pas une signature d’éditeur. Cette version pilote n’est pas signée par un éditeur vérifié ni notarisée par Apple ; des avertissements ou blocages du système sont possibles.

Le pilote utilise exclusivement des échanges fictifs. La sécurisation des fichiers temporaires et la conformité doivent être finalisées avant utilisation de données patient. Le compte rendu doit être relu et corrigé.

Ce dépôt ne contient pas le code source de l’application. Les bibliothèques tierces restent soumises à leurs licences, incluses dans les installateurs.
